# Super-Store-Sales-Dashboard
📊 Super Store Sales Dashboard – Power BI
This repository contains an interactive Power BI dashboard built using the Superstore dataset.
The dashboard provides a complete analysis of sales performance, customer segments, categories, profit trend, YOY performance, and shipping insights across different U.S. states.
📁 Project Files Included
File	Description
Superstore_Dashboard.pbix	Main Power BI dashboard
dataset/superstore.csv	Raw dataset used for building the dashboard
images/dashboard.png	Screenshot preview of the dashboard
README.md	Project documentation
